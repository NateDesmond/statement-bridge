# Home / export / menu rebuild (Nate's cold walk, 2026-09-18). Standard: clean, beautiful, one decision at a time.

Principles: one primary action per screen; everything else collapsed by default; never show a control that has nothing to act on; never show the same information twice; visual hierarchy with three tiers (headline, body, quiet); plain words; no decoration that reads as something else.

## Defects, all required
1. Drop area: the "Choose files" button is off-centre and its label is left-aligned. Everything in the drop area is centred, the button is a normal centred pill.
2. Result card: ONE preview only (the table under the headline). The export settings sheet is CLOSED by default, opened by a single quiet link "Adjust what's exported", and it contains NO second preview: changes update the one table above it live.
3. Preview table: the sticky header must stay fixed for every column including the sticky first column (fix the CSS: the top-left cell needs sticky top AND left with a higher z-index and an opaque background).
4. "Copy to Google Sheets": a normal-width primary button (auto width, min 220 px) with a copy icon (inline SVG), centred with "Download CSV" beside it. Not full width.
5. Decision cards for OCR rows: (a) BUG: some cards show a snippet from a different transaction. Root-cause the snippet source mapping (row → source_page/source_y for grouped blocks; check off-by-one when the description spans lines, page index base, and cases where the amount line is not the block's first line) with a test that asserts the snippet region contains the row's own amount text for every row of the 3-page and OCR fixtures. (b) The snippet must give context: the full transaction block (all its lines) plus half a line above and below, at legible size, in ONE crop (no two-piece split); the card grows to fit. (c) Far fewer flags: low-confidence only when the amount token confidence is below 60 AND the digit-whitelist retry disagrees with the first pass, or the value fails a sanity check (no decimals in a 2-decimal file, amount > 100x the file median); "sign unclear" only when neither a sign nor a marker nor a column position gave the sign. Measure on the OCR fixtures and the real private file: report flags before/after; target under 3% of rows flagged.
6. BUG: "possible duplicate" fired for the same vendor and amount on different dates. The within-file duplicate flag needs same date AND amount AND description; across files it is the cross-file merge only. Test with two coffee purchases on different days.
7. Columns: replace the checkbox list with layouts. Offer 6 presets as radio cards with a one-line description and a tiny column strip: "Simple" (Date, Description, Amount), "With account" (Date, Account, Description, Amount, Currency), "With balance" (+ Balance), "Budget app" (Date, Payee, Amount, Category empty), "Accounting" (Date, Description, Debit, Credit, Balance), "Everything". Below: "Customise" (collapsed) with only the columns that EXIST in this session as toggle pills in one row, drag to reorder; never list fields with no data. Keep "Last used" behaviour (the chosen layout and any customisation persist).
8. Merge "Coverage by account" and "Sources" into ONE table: Account | Statements (file names) | Rows in range | Include (switch) | actions (Check, Set up again, Remove). Nothing about accounts elsewhere in the sheet.
9. Date range presets and currency mode stay in the sheet but as two compact rows with a single control each; mode B details appear only when B is chosen.
10. The gear reads as a sun. Replace with a proper gear icon (inline SVG, 24 px) labelled "Settings" on hover/tooltip. The menu becomes a compact dropdown anchored to the gear (not a full-screen tile list): Statement types, Settings, How it works, Show welcome tour, Clear statements. Remove "Adjust what's exported" and "Check a statement" from the menu (they live on Home). Settings must not repeat the export layout: it holds preferences (start-from layout picker only), privacy and storage, saved rates, advanced.
11. "Report a problem" is a persistent quiet button bottom-right of every screen (a small bug icon + label), opening the report as a right-side sheet over the current screen, never a separate page.
12. Back: a real navigation stack. Back returns to the previous screen or closes the sheet/dropdown that was open; the brand name click goes Home.
13. Visual hierarchy pass on Home: headline tier (Your transactions are ready + number line), body tier (buttons, table), quiet tier (links, captions). Reduce the number of bordered boxes: file rows are a single list inside one card, decisions are one card, result is one card. Consistent 24 px section rhythm.
14. Processing stage: no options at all, just rows with progress and status; the export card appears only when at least one file is done.
