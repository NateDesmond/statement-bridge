Questions

Does my statement leave my computer?

No. Statement Bridge reads the file on your device. There is no server to send it to.

Do I need an account?

No. Open the extension and drop a file. That's the whole setup.

Which banks does it support?

Any bank whose CSV or PDF statement you can download, anywhere in the world. The first time you use a new bank's layout, Statement Bridge learns it in under a minute, then remembers it.

What if it reads something wrong?

You always see the extracted rows next to the original page before anything is saved, so you can check and fix a row in a click.

Does it work with scanned or photographed statements?

Yes. Statement Bridge can read those too, entirely on your device.

Why is this free?

It runs on your computer, so there are no servers for us to pay for. A small studio built it because we needed it ourselves. No data is collected or sold. If paid extras ever come along, the core of Statement Bridge stays free.
