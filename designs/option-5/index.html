About this design: The Vault

The 30-second path

Mapping a statement format is the one careful step, done once in the Vault's quiet mapping wizard. After that, Home is built for the other 11 months of the year: drop the files, watch the bar fill, click the brass Copy for Sheets button.

Nothing about that fast path hides the offline lock or the storage meter, both stay pinned in the sidebar footer no matter which screen is open.

Worth noticing: the export panel at the bottom of Home never asks a question that a warning can answer instead, only real blockers stop the Copy button.

How Statement Bridge works

Plain language, no marketing. This is what actually happens when you drop a file.

1. Everything happens in this tab

Your files are read by code bundled inside the extension: pdf.js for PDFs, Papa Parse for CSV, SheetJS for Excel. Nothing is uploaded. There is no server.

2. No AI

Suggestions for mapping columns come from simple rules: known header names in a few languages, and the shape of values such as dates, amounts and currency codes. You confirm every suggestion, and the rules never change on their own.

3. It remembers formats, not your data

A profile is a small description of a layout: which row is the header, which column is the date. It is saved on this computer. Statement contents live only in this browser's storage and are deleted after 30 days, or sooner when you clear sessions.

4. The extension cannot reach the internet

Its security policy is set to connect-src 'none' and it asks for no website permissions, so Chrome itself blocks any network request. You can check: open chrome://extensions, click Details on Statement Bridge and see it has no site access, or open DevTools on this tab, choose Network, and run an import. The list stays empty.

5. What is stored where

Settings such as profiles, presets, saved rates and preferences stay until you delete them. Session data, meaning file contents, extracted rows and edits, is kept 30 days from last opened. "Clear sessions" and "Delete everything" in Settings remove them immediately.

Passwords for encrypted PDFs are used once to open the file and never stored.
