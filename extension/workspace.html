Setup tour

Drop your statements. Statement Bridge reads them on your computer and gives you a table you can copy into Google Sheets.

Everything happens in this tab

Your files are read by code bundled inside the extension (pdf.js for PDFs, Papa Parse for CSV, SheetJS for Excel). Nothing is uploaded; there is no server.

No AI

Suggestions for mapping columns come from simple rules: known header names in a few languages, and the shape of values (dates, amounts, currency codes). You confirm every suggestion, and the rules never change on their own.

It remembers formats, not your data

A statement type is a small description of a layout (which row is the header, which column is the date). It is saved on this computer. Statement contents live only in this browser's storage and are deleted after 30 days, or sooner when you clear statements.

The extension cannot reach the internet

Its security policy is set to connect-src 'none' and it asks for no website permissions, so Chrome itself blocks any network request. You can check: open chrome://extensions, click Details on Statement Bridge and see it has no site access; or open DevTools on this tab, choose Network, and run an import. The list stays empty.

What is stored where

Settings (statement types, column layouts, saved rates, preferences) stay until you delete them. Statement data (file contents, extracted rows, edits) is kept 30 days from last opened. "Clear statements" removes only the statement data, right away; "Erase everything" in Settings removes both.

Passwords for encrypted PDFs are used once to open the file and never stored.
